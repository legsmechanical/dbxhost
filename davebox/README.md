# dAVEBOx SA — the sequencer module

This folder is the dAVEBOx SA sequencer module: its DSP (`dsp/`), its UI
(`ui/`), the manual and the module's tests. It ships together with the rest of
this repo, so the [main README](../README.md) covers what dAVEBOx does and how
to install it.

- [The manual](https://legsmechanical.github.io/dbxhost/) (source:
  `docs/working/MANUAL-SA.draft.md`) and the [Quick Start](QUICKSTART.md)
- [CHANGELOG](CHANGELOG.md)
- `tests/run.sh` — the module's test suite
